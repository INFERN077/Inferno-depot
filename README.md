# Inferno-depot

## Prompts

- [`prompts/prompt-script-youtube-sans-visage.md`](prompts/prompt-script-youtube-sans-visage.md) : prompt détaillé pour écrire des scripts YouTube long format sans visage (divertissement, optimisés pour la rétention).
- [`prompts/SOURCES.md`](prompts/SOURCES.md) : les vidéos et le cours sur lesquels il repose, et les adaptations faites.

### Utilisation

1. Colle le prompt (tout ce qui suit la première ligne `---`) dans les instructions d'un Projet Claude, d'un GPT personnalisé, ou directement dans la conversation.
2. Pour chaque vidéo, remplis le bloc **ENTRÉES** : sujet, titre, miniature, durée, spectateur idéal, émotion, recherche.
3. Commence en `MODE : [PLAN D'ABORD]` pour valider les faits, la structure et le plan avant l'écriture complète.
4. Vérifie tous les éléments marqués `[À VÉRIFIER]` avant l'enregistrement.
